Who Am I


Saya lulusan TJKT yang tertarik pada logika di balik jaringan. Dibanding sekadar mengikuti langkah-langkah setting Mikrotik, saya lebih menikmati saat harus menghitung dan memecahkan logika subnetting dan IP Address.


Ketertarikan pada logika itu yang membawa saya ke Cybersecurity. Saya sadar, untuk benar-benar memahami cara kerja keamanan sebuah website dan database, saya juga harus paham cara membangunnya. Dari situlah saya mulai mendalami Web Development.


Saat ini saya fokus membangun ulang fundamental saya melalui project-project nyata, mulai dari membangun navbar responsive hingga portfolio ini, sebagai langkah awal menjadi Web Developer yang paham sisi keamanan.
